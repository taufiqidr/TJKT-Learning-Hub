Modul: Dasar Pengalamatan IPv4

TUJUAN PEMBELAJARAN

Setelah belajar, peserta didik mampu menjelaskan struktur IPv4, membedakan Network ID dan Host ID, serta menentukan jaringan dasar dari alamat dan subnet mask.

1. Apa itu IPv4?

IPv4 adalah alamat logis 32-bit yang ditulis dalam empat oktet desimal, masing-masing bernilai 0–255. Contoh: 192.168.10.25.

Ingat: alamat IP mengidentifikasi antarmuka perangkat, sedangkan subnet mask membantu menentukan bagian jaringan dan bagian host.

2. Subnet mask

Subnet mask umum 255.255.255.0 atau /24 berarti 24 bit pertama adalah bagian jaringan dan 8 bit terakhir bagian host.

Contoh 1
IP: 192.168.10.25/24
Network ID: 192.168.10.0
Host ID: bagian terakhir, yaitu 25
Broadcast: 192.168.10.255

3. Contoh /26

/26 memiliki ukuran blok 64: 0, 64, 128, 192.
IP 192.168.10.70/26 berada pada rentang 64–127.
Network ID: 192.168.10.64
Broadcast: 192.168.10.127
Host valid: 192.168.10.65–126

Rangkuman

  • IPv4 terdiri dari 4 oktet atau 32 bit.
  • Prefix/subnet mask membagi bagian network dan host.
  • Network ID adalah alamat awal subnet dan tidak diberikan kepada host.
  • Broadcast adalah alamat terakhir subnet.

Demonstrasi Praktik

Simulasi pemeriksaan konfigurasi IPv4

  1. Buka Command Prompt atau Terminal.
  2. Jalankan ipconfig pada Windows atau ip addr pada Linux.
  3. Catat IPv4 Address, Subnet Mask, dan Default Gateway.
  4. Uji koneksi gateway dengan perintah ping.
  5. Bandingkan hasil dengan konfigurasi jaringan laboratorium.
K3 dan privasi: jangan mengubah konfigurasi perangkat sekolah tanpa izin. Saat mengirim bukti, sembunyikan nama akun dan informasi pribadi.
